## Full Category List

### Project & Task Management

- Jira (Atlassian) — Premium / Enterprise — Widely used in enterprise product teams for issue tracking and Agile boards. (Cloud paid tiers; free tier for small teams)
- Trello — Free / Premium — Simple kanban boards for small teams
- Asana — Free / Paid — Workflows and timelines
- ClickUp — Free / Paid — All-in-one work management

### Test Management & Case Repositories

- TestRail — Paid — Professional test case management and reporting
- Xray (for Jira) — Paid — Jira-native test management plugin
- Zephyr — Paid — Jira-integrated test management
- TestLink — Free / Open Source — Lightweight for small projects

### Automation Frameworks & Tools

- Selenium — Free — Browser automation standard
- Playwright — Free — Fast cross-browser automation
- Cypress — Free / Paid dashboard — JavaScript-focused E2E testing
- Appium — Free — Mobile automation
- Robot Framework — Free — Keyword-driven automation

### API & Integration Testing

- Postman — Free / Paid — Manual + automated API workflows
- Insomnia — Free / Paid — Lightweight API client
- SoapUI / ReadyAPI — Free / Paid — SOAP & REST testing for legacy services

### CI / CD & Automation Runners

- GitHub Actions — Free / Paid — Integrated CI/CD with GitHub
- Jenkins — Free — Extensible self-hosted CI server
- GitLab CI — Free / Paid — Built-in CI for GitLab

### Performance & Load Testing

- Apache JMeter — Free — Load testing tool
- k6 — Free / Paid Cloud — JS-based load testing
- Gatling — Free / Paid — High-performance load testing

### Security & Vulnerability Testing

- OWASP ZAP — Free — Open-source web app security scanner
- Burp Suite — Community / Pro — Manual security testing toolkit
- Snyk — Free tier / Paid — Dependency & container scanning

### Cross-browser & Device Testing (Cloud)

- BrowserStack — Paid — Real-device cloud testing
- Sauce Labs — Paid — Cross-browser & mobile cloud
- LambdaTest — Paid / Free tier — Cross-browser testing platform

### Monitoring & Observability

- Prometheus + Grafana — Free — Metrics and dashboards
- Datadog / New Relic — Paid — Enterprise monitoring suites

### Collaboration & Communication

- Slack — Free / Paid — Team chat and integrations
- Microsoft Teams — Free / Paid — Chat and meetings with Office365 integration
